# Optional record of ordinary checking or resumption

Record only work you did anyway. Leave any field blank or write “unknown”; no checking or reconstruction exercise is required.

- Which report or continuation did you assess?
- About how much active time did you spend checking or reconstructing it? Mark an estimate as an estimate; exclude time waiting for work to finish.
- What did you consult or repeat, if anything?
- Could you make the intended decision? What did you decide, or what remained missing?
- About how much extra time did making this record take?

A missing answer leaves effort unknown. This record is evidence about the reported episode, not a comparison showing saved effort. Keep the record local unless a specific projection is cleared for publication.
