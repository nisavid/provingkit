# Compare complete workflows and endpoint costs

The claim-support comparison will keep ordinary authoring, deterministic source preparation, Jev, Decisions, and ordinary Responses models eligible. This prepares two independently reviewable contracts; no experimental requests have been accepted by this scope decision.

## Proposed model matrix

| Candidate | Requested interface | Effort | Published short-context Standard USD per million tokens |
| --- | --- | --- | --- |
| Jev Choice | TypeSafe System One API | Not an ordinary-model effort setting | Input 0.042; output free |
| Decisions Choice | OpenAI Decisions, gpt-6-luna | No documented effort control | Input 0.10; no cache or output charges |
| Luna direct relation judgment | OpenAI Responses, gpt-6-luna | Low, Medium, High as separate conditions | Input 0.10; cached input 0.01; cache writes 0.125; output 0.50 |
| Sol direct relation judgment | OpenAI Responses, gpt-6.1-sol | Low | Input 2.00; cached input 0.10; cache writes 2.50; output 10.00 |

These six semantic conditions receive equivalent source bytes and question/option meanings. Ordinary authoring and deterministic-only preparation remain workflow alternatives, not fictional zero-cost inference conditions. Generated probabilities from a Responses model are not provider distributions; compare categorical accuracy separately and retain native probability fields only where supplied. Decisions refusals and malformed or incomplete Responses output remain separate outcomes.

Use the requested Luna profiles and Sol Low as consumer profiles where the publication-coverage contract compares ordinary reconciliation with the deterministic view. No Jev or Decisions call is required to compare literal paths and digests. A separate semantic obligation question would need its own supported inputs and contract.

## Subscription and API route

The [ChatGPT plan-usage overview](https://developers.openai.com/siwc/token-sharing-open-source) and [inference guide](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference) document eligible Responses requests. They do not establish Decisions access through Pro. The current proposal therefore uses ordinary API billing for Decisions, following the operator's explicit fallback preference. This is a documented-route finding, not an observed rejection of a subscription request.

The [preview restrictions](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations) require streamed, nonstored Responses and disallow several ordinary API fields, including max_output_tokens. A subscription adapter must preserve these differences. Verify the actual account's supported model catalog and route before a trial. Credential presence and model availability are prerequisites to execution, not proof that a candidate works. No credential appears in a packet or report.

## Measurements

Retain each attempt's raw usage object, endpoint, requested and returned model, requested effort and any observable effective effort, processing tier, region, timestamps, terminal status, and failure. Distinguish omitted counters from explicit zero. Keep a source-linked price record with its retrieval date and digest, and refresh changed rates before execution.

For Responses, let I be input tokens, C cached input, W cache-write tokens, and O output tokens. Where these partitions are reported and consistent, API-rate equivalent is ((I-C-W) times input rate + C times cached rate + W times write rate + O times output rate) / 1,000,000. Reasoning tokens are included in output, so do not add them again. Preserve unreported partitions as unknown unless the endpoint contract establishes their value. Invalid partitions are an accounting failure, not numbers to clamp.

Decisions and Jev use input-only valuation at their respective endpoint rates. Unreported output usage does not prevent input-only valuation. Missing input usage does. Retain output counters if supplied even when their price is zero. The [Decisions guide](https://developers.openai.com/api/docs/guides/decisions) defines its endpoint-specific pricing; Responses uses the [model pricing table](https://developers.openai.com/api/docs/pricing). Verify long-context, region, and tier adjustments for the actual request. Jev's current model and rates come from [TypeSafe's model documentation](https://docs.typesafe.ai/models).

Report three distinct quantities: calculated API-rate equivalent, attributable provider-confirmed charges, and observed subscription usage. A request-cost estimate is not an invoice or a quota conversion. Provider billing evidence may be unavailable; retain that limitation while still calculating the supported estimate. Every failed, discarded, unused, and retried attempt contributes its known usage and elapsed time; unknown failure cost is not zero.

Measure input acquisition, rendering, request start through terminal response, response validation, and downstream consumer work separately, plus total time to a usable result. First-byte or first-visible-output timing is optional and distinct from complete typed-answer latency. Use monotonic intervals for durations and UTC timestamps for ordering. Count shared production once in a joined workflow while retaining each arm's standalone cost. Separate one-time research, implementation, review, and grading from recurring production costs. Include required review, correction, fallback, operator effort, and interruptions rather than pricing only the classifier request.

## Qualification and next work

Local producer tests use the operator-confirmed CLI and resulting evidence packages. Successful preparation qualifies mechanics only. The runnable contracts still need frozen payloads and grader inputs, execution order and repetitions, output validation, route and credential setup, hard resource bounds, failure/stopping behavior, and source/protocol review before execution acceptance.

The claim-support contract must distinguish a supplied-case classification from a useful earlier author correction. The coverage contract must distinguish a correct relationship table from improved interpretation or reduced reconciliation work. Neither permits inferred safety benefit, general economic superiority, or replacement of required review without measured evidence.
