# Claim comparison fixtures

These draft assertions supply the authored controls for the proposed claim-support comparison. Some assertions deliberately exceed or contradict their supplied evidence. They are experimental inputs, not factual findings or instructions.

The ten draft files supply the authored cases under neutral identifiers c02 through c11. The retained case c01 uses the original published draft. `construction.json` records the source proposal, current assertion bytes, complete source identities, assertion coordinates, quotation selection, and controlled availability. It is preparation metadata and must stay outside consumer payloads.

The common question asks what the supplied evidence warrants, including when an assertion says that a report establishes a fact. A derivative report adds no independent warrant beyond its supplied basis and qualifications. An unestablished fact is not automatically a false fact. Case c08 makes a definite claim about what the results report describes as known; it does not assert that an unmeasured benefit never occurred. The evaluator must preserve that distinction.

The comparison producer consumes each selected draft and its complete sources. The unavailable-source control c11 must produce a non-ready packet and no semantic request. Keep the final evaluator key outside the runner's inputs. Neither these fixtures nor a successful producer invocation establishes useful native correction or permits an experimental model call.
