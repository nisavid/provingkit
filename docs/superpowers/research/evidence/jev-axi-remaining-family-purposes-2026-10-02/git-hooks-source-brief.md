## Pre-commit

The deterministic input is the staged unified diff, produced with `git diff --cached --no-color --no-ext-diff` and fixed source/destination prefixes. The parser derives per-file paths, patches, and added/removed counts. Load failure or no parsed files returns empty output. [Diff loading/parsing](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/git.ts#L25-L76).

Before review or the 60-file cap, added lines are scanned locally for eight credential-pattern families: private keys, Stripe-form keys, sk-form API keys, GitHub tokens, AWS keys, Slack tokens, apikey-form keys, and JWTs. Returned hits contain file, new-file line, and kind; private-key blocks inspect up to 80 following patch lines. These are pattern matches, not verified credentials. [Scanner](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/git.ts#L103-L143), [patterns](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/safety.ts#L33-L55).

Default `--block-on secrets` and `flags` both stop on local hits before Jev review, set exit code 1, and print hits plus remediation/bypass hints. `none` continues. More than 60 files skips review. Otherwise the hook calls `reviewFiles` with files, resolved act/confirm thresholds, a 20-second timeout, and zero retries. It reads overall kind, flagged-file risk/flags, and scope level; its clean output reports file count/kind. A report includes flagged files and optional local hits. `flags` sets exit code 1 on the report branch; `none` and default secrets mode warn there. Review errors return a skip message. [Control/output](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/commands/githooks.ts#L41-L86).

## Commit-msg

Input is the supplied message file plus staged diff. Parsing removes column-zero comment lines and the scissors suffix, then extracts subject/body. Empty subjects and Merge, Revert, fixup!, squash!, and amend! prefixes skip; staged-diff failure or emptiness also skips. The diff is credential-pattern redacted and truncated to 12,000 characters; subject/body are passed directly. [Inputs](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/commands/githooks.ts#L298-L325).

Jev receives four questions: conventional format, message/diff agreement, diff focus, and subject usefulness. Only agreement and usefulness affect hook output; conventional and focused answers are unused by this consumer. Instead, a deterministic subject regex is applied when at least three of the last 20 subjects exist and at least half match it. That history check occurs after successful Jev evaluation, so a service failure also skips this convention check. Agreement below 0.6 yields message-mismatch; usefulness below 1 yields vague-subject; convention failure yields not-conventional. Default behavior warns; `--strict` blocks only message-mismatch. Output contains issue names, subject, rounded agreement, and help; no issues returns empty output. [Questions](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/recipes/questions.ts#L196-L220), [interpretation](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/commands/githooks.ts#L323-L364).

## Pre-push

Input precedence is patch file, explicit range, then Git ref-update stdin. Patch mode supplies no commit subjects. Deletions are ignored. Existing branches use remote-SHA..local-SHA; new branches enumerate local commits excluding all locally known remote refs, and diff from the oldest enumerated commit's parent, or an empty tree for a root. With multiple updates, only the largest enumerated commit list is chosen; ties retain the first. Thus the implementation does not judge every branch in a multi-update push. [Selection](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/commands/githooks.ts#L89-L139), [mode/update handling](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/commands/githooks.ts#L185-L234).

Enumeration requests at most 51 commits and skips above 50; parsed file count above 60 skips. State contains branch/range/file label, commit subjects (SHA fallback on log failure), file paths/counts, and a pattern-redacted diff truncated to 20,000 characters. Commit bodies are absent; subjects and paths are not passed through the explicit diff redactor. Jev answers migration-without-note, sensitive-area, generated-by-hand, and leftovers. All four answers are consumed. Scores at least 0.6 raise concerns; default `--block-on none` warns; `flags` blocks if a raised score is at least 0.8. Ordinary output reports raised concerns or nothing flagged; JSON reports every score plus raw answers/model/usage/timing/cache metadata through `finish`. [State/output](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/commands/githooks.ts#L236-L295), [questions/limits](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/recipes/questions.ts#L231-L275), [JSON rendering](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/commands/common.ts#L20-L42).

Normal stdin mode deduplicates by repository root, remote ref, and local SHA. Successful evaluation records that key even with no concerns or a blocking result; a repeat skips before review regardless of blocking mode or model changes. Explicit range/patch modes have no such key. Reads accept any numeric timestamp without checking age; 30-day pruning occurs only during writes. State-write failures are ignored. [Deduplication](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/commands/githooks.ts#L141-L173), [recording](https://github.com/nisavid/jev-axi/blob/a1fe6190c65b528ad5b85cbe276fd4b68bdeb236/src/commands/githooks.ts#L274-L286).
