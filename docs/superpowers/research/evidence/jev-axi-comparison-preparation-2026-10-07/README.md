## Review and corrections

The independent preparations are preserved as [semantic first pass](semantic-first-pass.md) and [publication first pass](publication-first-pass.md). The linked current proposals incorporate the cross-informed review; the first passes are historical inputs, not the current answer keys.

The review found three material corrections:

- A claim that operator savings were measured contradicts the source's explicit statement that those measurements remain unknown. The revised semantic key grades that asserted measurement as contradicted, without claiming that improvement was impossible.
- A missing actual push range does not contradict a claim that a particular push occurred. The revised key treats the unsupported inference as an unsupported extension; this matrix does not yet test a genuine conflicting-source case.
- Overlay instructions and text announcing that a file is outside the manifest reveal the relationship a consumer should discover. Those examples remain mechanical checks. The current publication proposal adds separately identified neutral consumer variants and keeps their construction and answer key with the evaluator.

The coordinator independently checked the ten declared public source identities, all nine historical additions, the seven content digests, the separate review digest, and the two original overlay hashes. The final source review and its candidate identities are recorded with this package. These checks establish the supplied examples, not runtime behavior or complete research costs.
