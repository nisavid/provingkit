## Shared work and independent joins

Current requests and amendments, candidate/check identities, evidence supersession, reference availability, and discovery actions can serve more than one consumer. Reuse them only where scope and identities match. Completion asks whether reported work is supported; resumption asks what remains useful to do; discovery asks which path advances the task. One record need not serve every question.

Each contract joins its own input availability, accounting, and method suitability before acceptance. A natural task may expose both discovery and completion. Resumption can use another genuine pause without waiting for that task. Matching [staged/push evidence](../jev-axi-workflow-opportunities-2026-10-05/README.md) is a conditional input, not a whole-ticket dependency. Consequential-action research remains separately held for a qualified Daybreak route and does not block these ordinary preparations.

Collector preparation and local verification are next preparation work. Any native episode, Jev request, or live change still needs its applicable reviewed concrete contract and explicit execution acceptance. No new installed procedure or standing approval gate is proposed.
