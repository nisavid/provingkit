## Proposed supported input

Extend the existing [claim producer](../jev-axi-comparison-producers-2026-10-07/claim_producer.py) with an opt-in snapshot source kind while preserving its committed-input path. The first supported case would have:

- One immutable copy of an ordinary saved draft, its original location, exact bytes and digest, and a named checkpoint. Preserve the full draft as evidence, with assertion coordinates and enclosing qualifications selected explicitly.
- One complete report selected by an explicit local Markdown link, with its original location, exact bytes and digest, and revision or snapshot identity. A working snapshot must never be given a fictitious commit identity.
- The unchanged assertion, source selector, relevant draft context, and temporal scope: what this preserved report said. These fields must not contain an evaluator label, fidelity verdict, or rewritten statement that has already resolved the proposed judgment.
- Separate readiness and limitation records. Missing or changed bytes, invalid coordinates, an unresolved link, unsupported input, or incomplete context prevents a semantic request from being called ready. The ordinary workflow remains available, with any fallback work counted.

Changing either file invalidates the affected package. Preserve the earlier attempt and associate any successor with its own identities. An amended source needs an explicit relationship to the selected historical version; it must not silently replace that version. Exclude implicit source selection, unresolved multi-report conclusions, arbitrary interpretation enumeration, and reassessment of current merit from this first supported path.

The producer already checks committed identities and coordinates, retains complete sources, and withholds inference output for non-ready inputs. It neither discovers citations nor selects context. Selecting coordinates, confirming scope, and obtaining a stable snapshot remain real work; moving them into preparation does not make them free. The implementation proposal must account for those steps rather than assuming the author supplies a costless specification.
