## Coordinator's provisional next preparation

The relevant question is whether the proposed representation can be produced without consuming the expensive reasoning it is meant to save. A source may already have stable item IDs and a complete bounded list of candidates. That differs from asking an ordinary model to discover every possible meaning of arbitrary prose. The latter may perform most of the semantic work before Jev sees the statement.

For a preparation proposal, identify one real supported input with existing identities and selectors. Trace how the original statement, valid alternatives, qualifications, and evidence become available. Separate deterministic selection from semantic interpretation. Explain which remaining relation Jev would judge and how it would differ from code alone, ordinary reasoning, omission, and the agreed ordinary-model alternatives. Its material-ambiguity, immaterial-ambiguity, negation, unsupported-extension, and explicit-selection contrasts would test a different representation.
