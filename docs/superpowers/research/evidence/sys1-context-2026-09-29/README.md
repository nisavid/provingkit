# Native context and accounting evidence

These records support the [Sys1 context and accounting qualification](../../2026-09-29-sys1-context-and-accounting-source-read.md). They cover one fresh seven-turn Claude session, one fresh seven-turn Codex session, and a Codex preflight attempt that stopped before sending a user turn. They contain synthetic excerpts, measurements, review outcomes, and source identities. They establish no comparative Jev result or production authorization policy.

- [Claude observation](claude-native-context-r2-projection.json) and [independent review](claude-context-result-review.json): ordered first-read user context, actual assistant referent, bounded native effects, and reconciled reported usage.
- [Codex observation](codex-native-context-r3-projection.json) and [independent review](codex-context-result-review.json): the same boundary, plus completed and persisted native history.
- [Synthetic context excerpts](native-context-excerpts.json): exact matched user turns, actual assistant referents, and role/order positions. Project paths are normalized to `<project>`; unrelated native context is omitted.
- [Retained Claude usage reconciliation](claude-usage-reconciliation.json): completed-result and cumulative fields, repeated message identity, and incomplete iteration detail.
- [Codex preflight failure](codex-preflight-r2-projection.json): the implicit-workspace-root representation that the first check rejected. No user turn was submitted.
- [Codex schema observations](codex-schema-observations.json): public reported-token notifications and the unavailable internal per-response notification. These hashes identify schemas generated by the installed CLI.
- [Reviewed probe contracts](probe-contract-r2.md), [Codex preflight correction](probe-contract-r3.md), and [review outcomes](probe-reviews.json): the unexecuted first revision's findings, their fixes, and the clean pre-execution reviews.
- [Source identities](sources/identities.json): original executed/tested SHA-256 values and normalized archival source hashes. The r2 launcher produced the Claude result; the r3 launcher produced the Codex result. Common hook, reader, and grader source is unchanged between those runs. Source snapshots replace the local synthetic scratch prefix with `<scratch>` and retain a `.txt` suffix; they are evidence, not an executable or installed procedure.

Raw native records remain local because they include harness context outside the synthetic excerpt. The projections retain their hashes and identify their selected observations. The independent audits read those originals. The extraction normalizes paths; it does not replace a missing context read or supply an authorization decision to a hook.

Each successful run deliberately adds a 100 ms second-read delay at ten hooks. Primary read times exclude that delay and the rest of hook startup. Episode times include it. Preparation, research, review, and human effort are not interchangeable with those intervals; unmeasured effort remains unknown. The Codex failure is retained with the successful attempts rather than discarded from setup evidence.
