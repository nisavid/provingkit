Preserve supported uncataloged settings through researched native-tool use and existing authority. Apply [contextual judgment](https://github.com/nisavid/provingkit/issues/373): honor informed choices, explain consequential tradeoffs, cite applicable policy, and intervene for concrete active harm. An intended freeze is valid.

Keep maintained source, behavioral evidence, published artifacts, installed state, fresh discovery, useful invocation, and hosted enforcement as separate claims.
