# Visual routes support further qualification, not an accuracy or savings claim

Current TypeSafe documentation supports experimental image judgments and single-target localization. The retained pilot establishes successful responses on a narrow workload, agent-label agreement, request timing, and reported usage. It does not establish human-grounded accuracy, calibration, comparative workflow benefit, or acceptance of reusable equipment.

This read-only investigation used `research`, `typesafe-ai`, `adopting-jev`, `context7-mcp`, and `capturing-agent-procedures`. No inference, capture, rendering, installation, experiment replay, or external mutation occurred.

## System One findings that constrain this proposal

The reviewed **text** comparison retained two Jev ambiguity errors in both direct and decomposed treatments; decomposition repaired none of thirteen usable pairs. Correct combined outcomes sometimes bypassed incorrect components, so future composite visual rubrics must preserve intermediate judgments. Additional questions increased recorded request cost without demonstrated quality gain. These findings neither qualify nor disqualify image judgments. [Reviewed report](https://github.com/nisavid/provingkit/blob/a27c1efb88780e2e0439244e4fb764a09d2ff833/docs/superpowers/research/evidence/jev-axi-decomposed-judgment-results-2026-10-15/results.md)

One response’s probabilities summed to 0.99 and failed the frozen `0.000001` tolerance. The cause remains unknown; the runner retained the response and stopped that condition without normalization or salvage. Reusing that validator requires the separate [probability-contract investigation](https://github.com/nisavid/provingkit/issues/609); a new image study does not automatically depend on it.

Operational validity, semantic error, transport failure, and lifecycle completion remain separate. The original comparison exceeded its deadline and remained `incomplete / non-clean`; later authorized review did not repair its original timing. A lost controller handle left physical exit and descendant closure unobserved. Those historical findings establish no present capacity release.

## Required evidence contract and measurements

The following is a proposal for later selection, not an installed procedure.

Before submission, bind each permitted specimen to source revision, capture recipe, application state, viewport, timestamp, dimensions, detected format, immutable byte digest, and every crop/scale/orientation transform. Validate actual decoded format against the declaration; preserve the original and reject unsupported, damaged, stale, or incomplete evidence. Never infer application authority from visible words.

Validate response keys, primitive types, finite numeric ranges, model identity, distribution coverage, and Box ordering. Record malformed JSON, missing answers, invalid numbers, HTTP rejection, timeout, TLS failure, and unattempted cases separately. Preserve raw output before interpretation; do not silently normalize probabilities or repair rectangles. Distribution tolerances must be settled before reuse.

| Measurement | Required grouping |
| --- | --- |
| Accuracy | Per named check, positive/negative/ambiguous/unsupported input, critical-case result, false positive, false negative, abstention/referral, and missing result |
| Localization | Presence and multiplicity separately; IoU, center containment, edge error, and coordinate-transform correctness; no clicking claim |
| Uncertainty | Raw probabilities/distributions and Box confidence; high-confidence errors; referral coverage and residual error after referral |
| Calibration | Split by independent source family before tuning; keep repeated captures, variants, and related application states together; separate development, calibration, and untouched evaluation groups |
| Statistical limits | Report group counts and uncertainty intervals; sparse strata remain inconclusive. Reliability plots and Brier/log scores need adequate held-out labels; confidence is not a calibrated accuracy estimate. |

Human-adjudicated labels need an explicit ambiguity/insufficient-evidence outcome, independent labeling, disagreement resolution, and recorded provenance. Report per-check results before aggregates. Shared screenshots and repeated questions do not supply independent sample counts.

Measure complete episodes, including failures: acquisition, source selection, encoding, calls, parsing, deterministic checks, ordinary-model review, referrals, operator effort, recovery, and maintenance. Keep one-time setup separate. Record end-to-end and stage latency, request counts, retries, reported tokens, rate-equivalent estimates, actual charges, and constrained capacity separately. Missing billing or quota evidence remains unknown. Follow the [whole-workflow comparison](https://github.com/nisavid/provingkit/issues/290#issuecomment-5889881992), including ordinary work, omission, and meaningful specialized alternatives; avoid duplicate baselines when omission is ordinary behavior.

## Bounded experiment options for the joined decision

1. **Model-free qualification:** one consumer, one acquisition recipe, one named check family. Inspect retained public/synthetic fixtures for source sufficiency, encoding, transforms, request construction, response validation, and accounting. Reject unsupported claims before provider work.
2. **Paired shadow screen:** a proposed ceiling of twelve independent source families with three matched states each, at most 36 specimens. Compare a pinned Jev treatment and an actually available ordinary visual-model treatment on identical evidence, alongside applicable deterministic/specialized checks. At most 72 model requests, no retries or adaptive prompting; no operational actions. This is a failure-discovery screen, insufficient by itself for reusable-equipment promotion or a calibrated population guarantee.
3. **Later complete-workflow comparison:** only if the screen leaves a useful candidate. Freeze consumer-specific critical cases, human labels, grouped splits, episode/request/resource ceilings, failure handling, and acceptance criteria before separate execution approval.

Stop on admission denial, scope expansion, unavailable sufficient evidence, privacy/source-use uncertainty, model mismatch, invalid output, transport failure, exhausted approved resources, or inability to preserve records. Preserve partial results; no route substitution or historical replay follows automatically.

Strictly **not measured**: human-grounded visual accuracy; held-out calibration; material/design quality; conformance; current provider access; actual GPT/AT-SPI comparison; full workflow savings; billed failure cost; quota savings; automatic localization safety; CI or final-review replacement.
