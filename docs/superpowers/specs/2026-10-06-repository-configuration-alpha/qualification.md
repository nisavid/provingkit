# Repository-configuration alpha qualification contract

This contract defines the evidence required for a useful Mergecraft repository-configuration alpha: five complete GitHub workflows, adaptable judgment, live personal/public and organization/private use, and fresh discovery and useful invocation in Codex, Claude Code, and Cursor. It records the definition for [Define the alpha's behavioral qualification contract](https://github.com/nisavid/provingkit/issues/376). The operator authorized the two hosted fixtures, their create/test/retain scope, free standard GitHub Actions on the public fixture, and standard GitHub Actions on the private fixture within verified included allowance. No additional CI charges are authorized. The operator's current CI direction is GitHub Actions unless and until separately changed.

## Claims and phases

The alpha supports creating a repository, assessing existing configuration, adopting recommended defaults, making a focused change, and adding project-specific CI hardening, including authorized application through existing tools. Qualification establishes the selected representative cases and recorded limits. It does not establish an exhaustive settings catalog, every GitHub plan or owner arrangement, every client mode, or every workflow on every client.
