## Deterministic evidence and limits

The public command/socket test uses invented mailbox records and a disposable Unix peer. Its independent expected request checks Unicode/newline content, distinct origin/forwarder/obligation owner, message/exchange/attempt identities, native version and fields, and absence of settings overrides. The peer observes the create-only original attempt before replying. A successful empty RPC result remains possible submission with unknown receipt; no turn ID or opening-message receipt is invented. The same claimed attempt cannot reconnect, submit again, or alter prior captures. Owned stream EOF, fixture termination and child exit are recorded separately.

Five additional public-command examples vary wrong or missing thread kind, wrong or missing source, and a coherent busy runtime/turn observation. Each verifies refusal before peer input, unknown receipt and mailbox uncertainty, preserved message and claim, absence of native attempt/RPC files, and owned stream/thread/child closure. Bypassing the corresponding guard in a disposable source copy makes the expected refusal assertion fail; untouched production passes. These controls establish regression sensitivity, not a demonstrated pre-existing runtime defect.

The original missing-entry RED and first GREEN are retained. A subsequent causal RED exposed an unsupported mode restriction; the correction accepts the supplied durable/default/user example while keeping the exact kind/source requirements. The setup/observer failure before that causal RED remains separate. Missing-mode handling is source-inspected rather than separately exercised. Existing busy-path regressions retain their actual revision and evidence scope; final owning validation and independent review must cover the published candidate.

The prototype does not parse opening receipt from optimistic fields, RPC success, or the existing steering receipt predicate. The remaining server-history-to-snapshot provenance link is explicit. The earlier accepted idle-wake case offers a smaller independent same-chat observation/ACK method for a later qualification proposal; source work does not spend that historical grant again.
