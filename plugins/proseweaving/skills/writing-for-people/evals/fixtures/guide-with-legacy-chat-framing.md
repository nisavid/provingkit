# Public guide assignment

The reader is setting up an export for the first time. Deliver a short guide with the headings "Before you start", "Create the export", and "Check the result", plus a final one-sentence recap. The same headings appear in adjacent guides and help readers navigate.

Facts: A project needs a selected dataset and a destination folder. In the project settings, select the dataset and folder, then choose Create export. When the status reads Complete, the folder contains report.csv. If the status reads Failed, open Details to read the reported error. The guide should include all of these steps. There is no promise about how long an export takes.
