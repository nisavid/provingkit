# Partial Selection Controls

Delegation, same-purpose ownership, authority, isolation, and assurance are
settled. These are ordinary recoverable implementation tasks, with judgment
adequate at medium effort. Current exact-surface catalog and executor-schema
observations prove gpt-6.1-sol/medium on the Codex targets and opus/medium
(Claude Opus 5.5) on the Claude Code targets. No newer same-name successor is
advertised. Global and parent defaults are gpt-daybreak-blue-latest/xhigh or
opus/high. No account switch, probe, or extra worker is authorized. These are
controlled schema observations, not claims about every installed version.

For each harness, evaluate all four independently observed surface versions.
A. A model-only surface accepts the proven model but rejects an effort key;
the environment's fixed effort is medium.
B. The same model-only schema has an unknown fixed effort.
C. A no-model surface accepts effort; its fixed inherited model is the proven
model for that harness, and medium is accepted as the effort value.
D. A surface has neither field and an observed fixed binding to that harness's
proven model/medium. A neighboring installation has no observed binding.
Return request fields, recorded bindings and reasons, and dispatch disposition
for each version. Do not combine schemas from different versions.
