# General Model Tiers

Use these tiers only for work outside the three security classes after checking complete-operation Jev suitability. Select the lowest-cost proven pair preserving the assignment's judgment margin. Assess worker and orchestrator needs separately, including implementers, reviewers, writers, and integrators.

GPT-6 Sol and Claude Opus 5.5 handle ordinary demanding work. Start precise, recoverable implementation, debugging, analysis, and focused tests on a supported Sol `low` pair when its judgment margin suffices; raise effort with task demands. Default an independent reviewer to Sol `high` when the review is consequential but lacks the exceptional high-stakes cognitive conjunction below. Prefer Claude for UI, UX, and visual design, and GPT for review. These preferences do not change a frozen worker target or grant dispatch authority.

| Effort | Required judgment |
| --- | --- |
| `ultra` / `ultracode` | Highly parallelizable orchestration that benefits from this effort; use the form the exact target accepts. |
| `max` | Both (extremely challenging or full of risky unknowns) **and** (hard to reverse or expensive to get wrong). Opus 5.5 is never eligible for `max`. |
| `xhigh` | Hard or complex, substantial unknowns, hard to reverse, or expensive mistakes; any one condition suffices. |
| `high` | Somewhat hard or complex work that is relatively well understood; the normal consequential-review starting point. |
| `medium` | Some complexity with well-understood behavior. |
| `low` | Defined, recoverable work with enough judgment margin at this effort. |

Choose from the target's supported efforts, rather than assuming every model exposes the table. Claude Opus 5.5 permits `xhigh` or lower, or `ultracode` where supported, never `max`. Availability alone does not justify a higher effort.

For moderately complex, well-understood work that is not very quality-sensitive, consider GPT-6 Luna `xhigh`, Claude Opus 5.5 `low`, or Grok 4.7 `high`. For simple, well-understood work that is not quality-sensitive, consider GPT-6 Luna `high` or Grok 4.7 `low`. These alternatives have no fixed preference order; prove the exact pair on the chosen target.

Reserve GPT-6 Astra or Claude Fable 5.1 for work that is both **high-stakes** and demands at least one of deep cognition, intuitive hypothesis, analysis or synthesis, thoughtful articulation, or judgment over substantial unknown unknowns. Complexity or a named cognitive need without high stakes stays on Sol or Opus. Astra is the more economical exceptional option; use it for a bounded assignment that preserves the high-stakes judgment, not to enlarge scope. Use Fable for choicest beneficial deep work only with a current successful [target proof](capability-probes-and-fallbacks.md#prove-fable). This general-tier conjunction does not replace the more specific Fable security fallback rule.
