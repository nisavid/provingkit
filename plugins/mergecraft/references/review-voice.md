# Review Voice

Use this reference when authoring review findings, submitted-review summaries,
or responses to review feedback. PR and Issue body summaries keep the register
their publication purpose needs. A formatting-only request changes only the
authorized source form; it does not authorize rewriting prose or retained spans.

## Compose The Writing Route

Invoke `proseweaving:writing-for-people` when available before fixing the
response bytes. Apply its generic prose mechanics alongside the review rules
below and the separate GitHub Markdown authoring contract. Record the selected
source revision and any unavailable route in the caller's handoff, outside the
exact body. These review-shape rules stand alone; Proseweaving supplies the
generic register. When Proseweaving is absent, the client's ambient writing
instructions govern, without a claim that Proseweaving ran.

Writing policy shapes wording. The caller retains finding adjudication,
field selection, retained-span dispositions, and any publication authority.

## Findings And Asks

Lead a finding with the concrete behavior and its consequence. Include useful
credit when it helps explain the concern, and distinguish verified facts from
what remains unchecked. Connect the smallest proposed remedy to the failure it
addresses. Keep each comment focused on one finding and, when action is needed,
one coherent ask; an answer or completed-action report may need no ask.

Match the ask to the established finding:

- Default to a declinable question, such as “Could we retain the retry limit?”
- For a genuine blocker, use “Please” plus an imperative and explain the
  consequence that makes the fix necessary.
- For obvious cleanup, use “Let's” with the concrete change.
- For a confident nonblocking judgment, use first-person conviction, such as
  “I'd keep this check beside the conversion.”

Keep cosmetic preferences optional; use `Nit:` when identifying a nitpick.
Preserve the review's severity and uncertainty instead of turning confidence
or a small fix into a blocker. A finding can use a short title or a supplied
severity label when that helps the reader; let its substance carry the point.

## Replies And Review Summaries

For a reply, answer the live question or state the resulting action. Include
the evidence, correction, or tradeoff the reviewer needs without repeating the
comment or justifying the suggestion. Preserve a required source permalink and
the caller's field and thread placement.

For a submitted-review body, lead with the verdict, then explain remaining
blockers, residual gaps, and the observed checks status. Synthesize the inline
findings rather than restating their threads. On re-review, explain what the
new revision resolved; if the verdict changes, give the reason. Keep confidence
in the reviewed change separate from merge readiness or authority to approve.
