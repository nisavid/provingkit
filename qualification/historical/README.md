# Historical Task Witness qualification source

This directory preserves the exact Linux qualification and macOS host-probe implementation blocks adopted by the [nisavid/agents source inventory](https://github.com/nisavid/agents/issues/64#issuecomment-5494671865).

The files are outside GitHub Actions and normal test discovery because their repository, branch, candidate, and host assumptions are historical. The Linux run exercised an older candidate on GitHub-hosted Ubuntu. The macOS workflow was a GitHub-hosted host probe and did not execute that candidate. Neither is current Provingkit, hatchery, work-macOS, or live-route qualification.

The source remains available for the destination promotion-chain and qualification owners to rebind and review. Moving it here grants no workflow, host, release, installation, or publication authority.
