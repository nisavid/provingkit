# Medium and register source placement

The [accepted writing contract](https://github.com/nisavid/provingkit/issues/109#issuecomment-5724287968)
governs the split in [Split writing-for-people by concern](https://github.com/nisavid/provingkit/issues/26).
This record accounts for the canonical source contributions being restructured;
it does not retire an installed route or revise the disposition of an external
specialist.

| Contribution | Maintained location and treatment |
| --- | --- |
| Grounding, audience, plain language, and useful precision | Retain in the portable entrypoint, applying them to the reader and artifact rather than assuming a chat. |
| Openings and the writer's perspective | Generalize in the entrypoint: choose the medium, lead with the subject, and use first person when experience or judgment contributes. |
| PR-body exclusion | Replace with composition: generic prose applies to authored text; specialized content, format, retained bytes, and publication remain with their owners. |
| Conversational openings, reply etiquette, one coherent ask, stopping-point reports, and variation across comments | Move to the conditionally loaded `references/threaded-conversation.md`. A comment needing no ask can remain an answer or acknowledgment. |
| Review-specific severity and ask ladder | Remove from the generic skill. [Add the Mergecraft review-voice reference and projections](https://github.com/nisavid/provingkit/issues/19) owns this contribution; the prior canonical wording is retained in Git at `9f703468fc7a634e63d890211b5c2e3c3e27f252`. Its forms distinguish declinable questions, blocking requests, cleanup, and personal conviction. |
| Organization and post-draft editing | Retain with medium-sensitive scope. Documents can need headings, tables, several decisions, consistent structures, and conclusions. Replies keep their conversational shape. |
| Source findings and runtime outcomes | Correct the overbroad unrun-outcome rule in the entrypoint and evidence reference. Inspected source can establish behavior; a claimed run or deployment result needs an observation. |
| Commitments, social facts, inference, and the system versus test setup | Preserve in the evidence reference. Label useful inference instead of disguising it as observation, and retain the scope of constructed tests. |
| Codex default prompt | Project the revised skill interface into the manifest so the entry route no longer makes a graded ask universal. |

The behavior corpus retains conversational regressions while removing mandatory
review-opening formulas and the review-specific ask ladder. Added contrasts
cover PR versus chat prose, Issue reports and proposals, a structured guide
under obsolete chat framing, a useful first-person publication opening, and
source findings versus observations from a constructed test.

The Mergecraft consumer owns imperative PR change summaries and its review
policy. Personal voice remains caller-owned. Global-instruction thinning and
source-route retirement belong to [Install updated Proseweaving, Versionkeeping,
and Mergecraft on Hatchery](https://github.com/nisavid/provingkit/issues/112),
after the replacement's discovery and coverage are verified.
