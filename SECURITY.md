# Security policy

## Supported versions

We maintain security fixes for the following versions:

| Version | Security-fix support |
| --- | --- |
| `main` | Maintained |
| `0.1.0-alpha.4` (the current supported alpha) | Maintained |
| Older alpha and preview snapshots | Assessed case by case |

We carry fixes forward into maintained source and subsequent alpha builds.
Published snapshots remain immutable. We assess older snapshots individually;
there is no general commitment to backport fixes.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/nisavid/provingkit/security/advisories/new)
to report a suspected vulnerability. Please avoid public issues or pull
requests that disclose an unresolved vulnerability.

Include the affected plugin, source revision or alpha version, steps to
reproduce the issue, and its potential impact. Use redacted examples or
disposable credentials rather than sending live secrets or unrelated private
data.

We handle reports on a best-effort basis, without a guaranteed response time,
resolution time, or disclosure deadline. We use the private report to discuss
the issue and coordinate a fix and appropriate disclosure.
